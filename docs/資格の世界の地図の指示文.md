# 資格の世界の「学びの地図」の指示文（ChatGPT に頼む用）

星詠みの書で二陸特（第二級陸上特殊無線技士）を選んだとき、学びの地図を「電波の王国」の絵に切り替えます。
アプリは、絵の上の決まった場所をタップすると各塔へ行くしくみです。**いまの地図と同じ配置**で描いてもらうのが大事です。

## 送り方

1. ChatGPT に新しい会話を作る
2. いまの学びの地図（イラストフォルダの「ChatGPT 画像 2026年10月22日 16_45_55.png」）を添付する
3. 下の文章をそのまま送る

```
添付の絵は、学習アプリ「Study Quest」の「学びの地図」です。
これと**まったく同じ配置・同じ構図**で、別の世界「電波の王国」の版を描いてください。

【配置（添付の絵と同じ場所に、同じ大きさで）】
・中央：はじまりの街（看板の文字「はじまりの街」）
・左上：周回の塔（看板「周回の塔」）
・右上：計算の塔（看板「計算の塔」）
・左下：修練の塔（看板「修練の塔」）
・右下：図書の塔（看板「図書の塔」）
・中央下：冒険の塔（看板「冒険の塔」）
・6つの場所を結ぶ道や橋も、添付の絵と同じ位置に。看板の文字と位置も添付の絵と同じに。

【世界観：電波の王国】
・空に浮かぶ島々と、港町。雷雲と稲妻が遠くに光る天空。
・建物には電波塔・パラボラアンテナ・送信所・灯台・回路の模様。光る電波の輪が空に広がる。
・はじまりの街は港町（白い壁・青い屋根、桟橋と小さな船）。
・周回の塔はアンテナの立つ時計塔、計算の塔は歯車と回路の工房の塔、修練の塔は雷を受ける試練の塔、図書の塔は通信の記録を収めた図書館、冒険の塔は嵐の電波塔へ続く飛行船の発着塔。
・色は青・白・金を基調に、電波の光は水色と黄色。明るく透明感のあるアニメ調のファンタジーイラスト。

【形】
・横長16:9。看板以外の文字（題名・ロゴ）は入れない。
```

## うまくいかないときのひとこと

- 配置がずれた：`添付の絵と同じ配置に戻してください。6つの場所の位置と大きさを、添付の絵にそろえてください。`
- 看板の文字がくずれた：`看板の文字を「周回の塔」「計算の塔」…のように、はっきり読める日本語にしてください。`
- 縦長になった：`横長16:9で描き直してください。`

## できた絵の入れ方

- イラストフォルダに入れて「電波の王国の地図を入れた」と伝える
- アプリでは `public/art/townmap-radio.webp` として入れる（横1600px ほど）。src/data/worlds.js の `townmap` に名前を登録済み
- 二陸特を選んでいるときの学びの地図・塔の見出しが、この絵に切り替わる（絵がないあいだは王都の地図のまま）
- 配置が少しずれたときは、App.jsx の `LEARN_TOWNS`（タップする場所）はそのままなので、絵のほうを合わせてもらうか、世界ごとの場所の設定を足す
