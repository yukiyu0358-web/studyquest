# まちづくりの絵の指示文（ChatGPT に頼む用）

Study Quest の「はじまりの街」は、勉強した分だけ **小屋 → 集落 → 村 → 町 → 街 → 王都** と6段階に育ちます。
各段階の絵を1枚ずつ（全部で6枚）作ってもらい、アプリに入れます。

## 6枚に共通の指示（毎回いっしょに貼る）

```
ファンタジーRPG「Study Quest」の街の成長を描く、6枚の連作の1枚を描いてください。

・絵柄：明るく透明感のあるアニメ調のファンタジーイラスト。白・金・青を基調に、空色の空と白い雲、緑の草原。
　（すでにある「学びの地図」の絵と同じ世界観：空に浮かぶ島々、水路と石の橋、白い壁に青い屋根の建物、金の装飾）
・構図：横長 16:9。少し高い位置から見下ろす同じ視点・同じ地形で、6枚とも「同じ場所が育っていく」ように描く。
　画面の中央に街、手前に道、奥に山と空。
・文字は入れない（題名・看板の文字・ロゴなし）。人物は小さく、街のにぎわいがわかる程度。
・測量と学びの国らしさ：測量の三脚、境界石、地図、本、星の紋章などを小物として少し入れる。
```

## 段階ごとの指示（共通の指示のあとに1つずつ貼る）

1. **小屋**（stage1）
```
第1段階「小屋」：草原にぽつんと建つ、木と石の小さな小屋が1軒。そばに測量の三脚と境界石。
小さな畑と井戸。旅のはじまりの、静かで希望のある朝。
```
2. **集落**（stage2）
```
第2段階「集落」：第1段階の小屋のまわりに、小さな家が4〜5軒増えた集落。細い土の道、たき火、洗濯物。
人が集まりはじめたあたたかさ。
```
3. **村**（stage3）
```
第3段階「村」：畑と井戸と小さな広場のある村。家は10軒ほど、白い壁に青い屋根が増える。
広場に掲示板、小さな図書館と測量所が見える。
```
4. **町**（stage4）
```
第4段階「町」：石畳の通りに店が並ぶ町。宿屋・学舎・時計台・市場がある。水路と小さな石の橋。
活気のある昼。
```
5. **街**（stage5）
```
第5段階「街」：水路と石の橋で結ばれた、にぎやかな街。城壁が広がり、遠くに塔へ続く道。
鍛冶屋の煙、旗、空を行く小さな飛行船。
```
6. **王都**（stage6）
```
第6段階「王都」：白い城がそびえる王都。青い屋根の尖塔、金の装飾、城の前の大広場に星の紋章。
空に浮かぶ島々と滝。夕方の光で、ここまでの道のりを祝うような壮大な景色。
```

## できた絵の入れ方

- 6枚をイラストフォルダ（`OneDrive\Desktop\studyquest-vite\イラスト`）に入れて、「まちづくりの絵を入れた」と伝える。
- アプリでは `public/art/town/stage1.webp` 〜 `stage6.webp` として入れる（横長 16:9、横1400px ほどに縮小）。
- 絵がない段階は、学びの地図の「はじまりの街」の部分を仮に表示している。
