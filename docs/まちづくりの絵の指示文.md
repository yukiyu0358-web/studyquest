# まちづくりの絵の指示文（ChatGPT に頼む用）

Study Quest の「はじまりの街」は、勉強した分だけ10段階に育ちます。
**小屋 → 開拓地 → 集落 → 村 → 宿場町 → 町 → 城下町 → 街 → 都 → 王都**
各段階の絵を1枚ずつ（全部で10枚）作ってもらい、アプリに入れます。

- ChatGPT の**1つの会話の中で、上から順に送る**（同じ会話で続けると、場所と視点がそろいやすい）
- 最初のメッセージには、学びの地図の絵（イラストフォルダの「ChatGPT 画像 2026年10月22日 16_45_55.png」）を添付すると世界観がそろう

## ① 1枚目（小屋）＋6枚に共通のルール

```
添付の絵と同じ世界観で、ファンタジーRPG「Study Quest」の「はじまりの街」が育っていく様子を、全10枚の連作で描いてください。今回は1枚目です。

【10枚に共通のルール】
・絵柄：明るく透明感のあるアニメ調のファンタジーイラスト。白・金・青を基調に、空色の空と白い雲、緑の草原。空に浮かぶ島々、水路と石の橋、白い壁に青い屋根の建物、金の装飾。
・構図：横長16:9。少し高い位置から見下ろす視点。10枚とも同じ場所・同じ地形・同じ視点で「同じ土地が少しずつ育っていく」ように描く。画面の中央に街、手前に道、奥に山と空。
・文字は入れない（題名・看板の文字・ロゴなし）。
・人物は小さく、にぎわいがわかる程度。
・測量と学びの国らしい小物（測量の三脚、境界石、地図、本、星の紋章）を少し入れる。

【1枚目：小屋】
草原にぽつんと建つ、木と石の小さな小屋が1軒。そばに測量の三脚と境界石。小さな井戸。旅のはじまりの、静かで希望のある朝。
```

## うまくいかないときのひとこと

- 構図が変わった：`1枚目と同じ視点・同じ地形に戻して、建物だけを増やしてください。`
- 文字が入った：`絵の中の文字・看板の文字をすべて消してください。`
- 縦長になった：`横長16:9で描き直してください。`

## できた絵の入れ方

- 10枚をイラストフォルダ（`OneDrive\Desktop\studyquest-vite\イラスト`）に入れて、「まちづくりの絵を入れた」と伝える（保存した順番のままでよい）
- アプリでは `public/art/town/stage1.webp` 〜 `stage10.webp` として入れる（横長16:9、横1400px ほどに縮小）
- 絵がない段階は、学びの地図の「はじまりの街」の部分を仮に表示している
